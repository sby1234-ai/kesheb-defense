## 2. 시연 순서 (약 5분)

### ① 켜기 (30초)
`on-client` 폴더에서 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1` → 브라우저 `http://127.0.0.1:5189`.
- 보여 줄 말: "회사 시스템(SDP)에는 연결하지 않은 기본 실행입니다. 위쪽 `연결 없음` 은 고장이 아니라 미연결 상태 표시입니다."

### ② 내 PC 관제 대시보드 (2분) — 기능 1
1. 「⟳ 다시 조회」를 두 번 누릅니다.
2. 종합 배너를 읽습니다. 연습 때 실제 화면: **「▲ 주의 1건 · 먼저 볼 항목: 방화벽 — 꺼진 프로필: Domain, Private, Public.」**
3. 카드 4개를 읽습니다. 연습 때 실제 값(09:26:12 실측):

   | 카드 | 값 | 판정 |
   |---|---|---|
   | CPU | 33.7% | ● 정상 |
   | 메모리 | 50.9% (8.1 GB / 15.8 GB) | ● 정상 |
   | 디스크 | 여유 12.1% (46.1 GB / 382.4 GB) | ● 정상 (여유 10% 미만이면 주의) |
   | 방화벽 | 켜진 프로필 0 / 3 | ▲ 주의 |

4. 아래 줄을 가리킵니다: 네트워크 `● 정상`(IPv4 구성 2개 — "인터넷 접속이나 ZTNA 허용 확인이 아님"), Windows 기록 `◆ 관찰`(24시간 오류 7·경고 31 — "침해·공격 탐지 결과가 아님"), SDP 서버 `○ SDP 미연결`("PC 실측 성공과는 별개").
5. 추이 그래프와 변화량을 보여 줍니다. 연습 때: `CPU ▼ −12.9%p`, `메모리 ▲ +0.6%p` (직전 측정 대비, 측정 2회).
6. 기록 표에서 「주의만」을 눌러 거르기를 보여 줍니다.
- 보여 줄 말: "같은 실측 값을 제공 카드는 숫자로만 보여 주고, 제 대시보드는 기준을 세워 **무엇부터 볼지**를 알려 줍니다. 앱은 설정을 읽기만 하고 바꾸지 않습니다. 「정상」도 '핵심 항목이 기준 안'이라는 뜻이지 보호 전체가 안전하다는 판정이 아닙니다."

### ③ 보안 기록 (1분) — 기능 2
「보안 기록」 탭을 엽니다. 연습 때 실제 화면:
> 기록을 불러오지 못했습니다: … (ENGINE_NOT_CONNECTED)
> 이 화면은 빈 기록 목록이 아니라 불러오기 실패입니다. 다시 시도하려면 위쪽 다시 불러오기 버튼을 직접 누르세요.
- 보여 줄 말: "회사 시스템이 연결되지 않아 기록이 없습니다. 이때 '기록 0건'으로 보이면 사고가 없다고 오해하므로, **실패라고 분명히 표시**하게 만들었습니다. 기록이 왔을 때의 목록·거르기·상세는 15단계 코드 검토로 통과했습니다."

### ④ 부풀리지 않는 표시 (1분) — 기능 3
1. 「보호 현황」의 「설치 패키지 조회」를 누릅니다. 연습 때 실제 화면: `조회 상태: 조회 준비 미완료(not_configured)` + **"아직 조회하지 않았다는 뜻이며 "취약점 없음"이 아닙니다."**
2. 「보안 기록」의 조치 표시: `조치: 아직 미실행(idle)` + 지원 조치가 없으면 버튼이 나오지 않는 것이 정상이라는 안내.
- 보여 줄 말: "조회를 못 한 것, 접수만 된 것(ACK)을 성공이나 안전으로 바꾸지 않는 것이 이 앱의 원칙입니다."

### ⑤ 마무리 (30초)
"되는 것은 내 PC 실측과 판정, 안 되는 것은 회사 시스템 연결이 필요한 기능입니다. 무엇이 안 되는지는 아래 한계에 그대로 적었습니다."

## 3. 한계 (안 되거나 확인 불가로 남은 것)

| 항목 | 상태 | 이유 |
|---|---|---|
| 접근 제어·XDR 시스템(SDP) 연결 | 미연결 | 접근 제어 서버·연결 어댑터·개인 인증서가 필요하며 이번 과정에서는 학생에게 발급하지 않음(포털 안내). 그래서 로그인·기기·세션·업무 앱 판정·보안 기록은 실제 값이 아니라 `연결 없음`/`요청 실패` 만 확인함 |
| 실제 조치 집행(19단계) | 미확인 | 원천 집행기 연결 미완료. 화면은 상태 표시만 함 |
| AI 사건 설명(17·18단계) | 미확인 | 이번 시연에서 실제 AI 설명을 받지 않음. 기본 실행에서 AI 연결은 별도 계정 연결·승인 절차가 필요 |
| OSV 취약점 실제 조회(20단계) | 미확인 | 허용된 공개 패키지 목록이 없어 `not_configured` 가 정상 상태 |
| 조회 실패 화면(`✕ 조회 실패`, `오래됨`) | 모의 입력으로만 확인 | 실제 화면에서 앱 서버를 끈 상태로 조회해 보지는 않음 |
| 포장·설치 프로그램 | 하지 않음 | 포털 안내: 포장에 필요한 실행 환경이 수강생 PC에 준비되지 않아 이번 과정에서 실행하지 않음 |
| 다른 PC·macOS·Linux 실행 | 미확인 | 같은 PC 에서만 새 폴더 재현 |
| 처음 보는 사람의 사용 관찰 | 미실시 | 다른 사람이 처음 써 보는 것을 관찰하지 않음 |
| 키보드·좁은 화면 | 일부 확인 | 2026-10-27 원래 폴더 앱에서 키보드 초점·좁은 화면 배치 확인. 200% 확대·화면 낭독기는 미확인 |

따라서 이 버전은 **검증 중인 버전**이며 v1.0 이 아닙니다.

### 연습 중 실제로 발견한 것
- 이 PC 는 Windows 방화벽 세 프로필(Domain·Private·Public)이 **모두 꺼져 있음**. 대시보드가 이를 `▲ 주의` 로 맨 위에 올렸습니다. 앱은 읽기만 하며 설정을 바꾸지 않았습니다. 방화벽을 켤지는 이 PC 관리자가 정할 일입니다.
