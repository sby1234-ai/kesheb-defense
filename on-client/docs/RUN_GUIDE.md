# 케셰브 실행 안내 (한 장)

처음 보는 사람이 이 한 장만 보고 앱을 켤 수 있게 쓴 학생 문서입니다. 자세한 설명과 구성도는 `docs/STUDENT_GUIDE.md` 에 있습니다.

## 준비물

| 필요한 것 | 확인 방법 |
|---|---|
| Windows PC | — |
| Git | PowerShell 에서 `git --version` 이 버전을 보여 주면 됨 |
| Node.js 22~24 (권장 24.19.0) | PowerShell 에서 `node --version` 이 `v22.x`~`v24.x` 이면 됨 |

`npm install` 은 필요 없습니다(외부 npm 의존성 없음). 관리자 권한도 필요 없습니다.

## 1. 받기 (처음 한 번)

PowerShell 을 열고 받을 위치에서 실행합니다.

```powershell
git clone https://github.com/sby1234-ai/kesheb-defense.git
cd kesheb-defense\on-client
```

이미 받은 폴더가 있으면 그 폴더의 `on-client` 에서 PowerShell 을 엽니다(파일 탐색기 주소 표시줄에 `powershell` 입력 → Enter).

## 2. 켜기

`on-client` 폴더에서 아래 한 줄을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

창에 아래처럼 나오면 정상입니다.

```
계정 연결 준비가 끝났습니다. 앱에서 확인 번호로 로그인·승인을 진행하세요.
케셰브가 켜졌습니다. 브라우저에서 http://127.0.0.1:5189/ 을 여세요.
서버가 응답한 것만 확인했습니다. AI 연결 상태는 화면에서 따로 확인해 주세요.
끄려면 이 창에서 Ctrl+C 를 누르세요.
```

- Node.js 가 24.19.0 이 아니면 첫 줄 다음에 `참고: 지금 Node.js 는 vXX 입니다. 수업 기준은 v24.19.0 입니다.` 가 한 줄 더 나옵니다. 22~24 범위면 그대로 써도 됩니다.
- 첫 줄의 "계정 연결 준비"는 로그인용 보관소를 이 PC 사용자 폴더에 준비했다는 뜻입니다. 로그인을 하지 않아도 앱은 켜집니다.
- **이 창은 닫지 마세요.** 창을 닫으면 앱도 꺼집니다.

## 3. 화면 확인

브라우저에서 **http://127.0.0.1:5189** 를 엽니다.

1. 「보호 현황」 화면 위쪽에 「케셰브」 배너가 보이고, 그 아래 학생 칸들 사이에 **「내 PC 관제 대시보드」** 가 있습니다. 맨 위 빨간 상자의 「기존 서버·에이전트의 연결을 확인할 수 없습니다」는 회사 시스템 미연결 안내입니다.
2. 대시보드의 **「⟳ 다시 조회」** 를 누르면 이 PC의 CPU·메모리·디스크·방화벽·네트워크·Windows 기록을 읽어 카드에 보여 줍니다(관리자 권한 없이 읽기만 함).
3. 다음은 고장이 아니라 기본 상태입니다.
   - 「SDP 미연결」, 「연결 없음 (disconnected)」: 회사 시스템에 연결하지 않은 기본 실행입니다.
   - 아래쪽 흰 카드 「내 PC 상태」: 시작 틀이 제공하는 원래 기능입니다. 자기 「내 PC 확인」 버튼으로 따로 조회합니다.

## 4. 끄기 · 다시 켜기

- 끄기: 2번 창에서 `Ctrl+C` (또는 창 닫기)
- 다시 켜기: 같은 `on-client` 폴더에서 2번 명령을 다시 실행하고 브라우저를 새로고침

## 막혔을 때

| 보이는 문구·증상 | 할 일 |
|---|---|
| `Node.js 가 없습니다` | https://nodejs.org 에서 Node.js 24.19.0 을 설치하고 **새 PowerShell 창**에서 다시 실행 |
| `지금 Node.js 는 vXX 입니다. 앱은 Node.js 22~24 에서 실행합니다.` | Node.js 22~24(권장 24.19.0)를 설치하고 새 창에서 다시 실행 |
| `포트 5189 를 다른 프로그램이 쓰고 있습니다` | 그 프로그램은 두고, 2번 명령 끝에 ` -Port 5190` 을 붙여 실행 → 주소도 `:5190` |
| `앱 폴더가 아닙니다` / `시작 틀 폴더가 아닙니다` | `on-client` 폴더 안에서 실행했는지 확인 |
| `앱 서버가 … 초 안에 뜨지 않았습니다` | 창의 메시지 전체를 담당 강사에게 보여 주기 |
| 브라우저에 "연결할 수 없음"(연결 거부) | 2번 창이 닫혔거나 꺼진 것 → 2번 명령으로 다시 켜기 |
| 대시보드에 `✕ 조회 실패` | 상자 안 "다음에 할 일"을 따릅니다(예: 앱 창이 켜져 있는지 확인 후 「다시 조회」) |
| 카드에 `? 확인 불가` | 그 항목을 읽지 못한 것입니다. 정상으로 보지 말고, 카드의 "다음에 할 일"을 따릅니다 |
